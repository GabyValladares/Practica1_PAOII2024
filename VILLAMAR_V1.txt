El versionamiento es como una herramienta para el desarrollo de un software ya que con esto podemos ir avanzando 
y guardando nuestro código para poder tener una comparativa de un antes y un después de un cambio 
nos permite poder tener un orden y hacer cambios sin afectar a lo que teníamos a parte de tener una forma rápida de poder 
mostrar nuestros avances a nuestro equipo de trabajo.

git init -> Inicia un nuevo repositorio de Git.

git add . -> Agrega los archivos actualizados para subirlos al repositorio remoto

git commit -m "descripción" -> Guarda los cambios en el repositorio con un mensaje descriptivo.

git push -> Empuja los archivos locales con el commit al repositorio remoto

git Branch -M master -> crea la rama principal

git Branch -> muestra las ramas 

git checkout Nombre_rama -> Cambia de rama 

git checkout -b nombre de la rama  -> crea rama y cambia a la rama creada

git pull -> descarga los datos del repositorio remoto al repositorio local en la computadora
